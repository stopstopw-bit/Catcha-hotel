# 🛠️ วิธีติดตั้งเฟส 2 — ต่อ Google Calendar (ทำครั้งเดียว ~15 นาที)

> ทำด้วยบัญชี Google **Stopstop.w@gmail.com** (บัญชีเจ้าของหลัก)
> ระบบจะใช้ปฏิทินร่วม **"Catcha Hotel"** (ชื่อเดียวกับที่เห็นใน Google Calendar) แล้วแชร์ให้ Chutchanok.than@gmail.com + pitchapawong.pw@gmail.com
> ทั้ง 2 คนเห็นนัดบนมือถือโดยตรง (ไม่ต้องกดรับคำเชิญทีละนัด)

---

## สเต็ป 1 — สร้างที่เก็บข้อมูล (Google Sheet)
1. เข้า https://sheets.google.com → กด **+ ว่าง** (Blank) สร้างชีตใหม่
2. ตั้งชื่อชีต (มุมซ้ายบน) เช่น **CatCha Hotel — Bookings**

## สเต็ป 2 — เปิด Apps Script
3. ในชีตนั้น เมนูบน → **ส่วนขยาย (Extensions)** → **Apps Script**
4. จะเปิดหน้าต่างโค้ดขึ้นมา มีไฟล์ `Code.gs` ว่างๆ (มี `function myFunction`)

## สเต็ป 3 — วางโค้ดหลังบ้าน
5. ลบโค้ดเดิมใน `Code.gs` ทิ้งทั้งหมด
6. ก็อปเนื้อหาไฟล์ [`apps-script/Code.gs`](Code.gs) มาวางแทน → กด 💾 **บันทึก**

## สเต็ป 4 — วางหน้าเว็บ
7. ข้างชื่อไฟล์ (ซ้ายมือ) กด **+** → **HTML**
8. ตั้งชื่อไฟล์ว่า **`Index`** เป๊ะๆ (ระบบจะต่อ `.html` ให้เอง)
9. ลบเนื้อหาเดิมในไฟล์ Index ทิ้ง → ก็อปเนื้อหาทั้งหมดของ [`webapp/index.html`](../webapp/index.html) มาวาง → 💾 บันทึก

## สเต็ป 4.5 — เปิด Google Calendar API
10. ใน Apps Script ซ้ายมือ → กด **+** ข้าง **Services**
11. เลือก **Google Calendar API** → กด **Add**
12. ต้องเห็นรายการ `Calendar` ใน Services

## สเต็ป 5 — เปิดสิทธิ์ + สร้างปฏิทินร่วม (สำคัญ)
13. ด้านบน เลือกฟังก์ชัน **`setup`** จากช่องดรอปดาวน์ → กด **▶ Run**
14. เด้งหน้าขออนุญาต → เลือกบัญชี **Stopstop.w** → กด **Advanced** → **Go to (unsafe)** → **Allow**
15. รันสำเร็จจะขึ้นข้อความว่าเชื่อมปฏิทิน **Catcha Hotel** แล้ว

## สเต็ป 5.5 — ส่งอีเมลแชร์ปฏิทิน (ถ้ายังไม่ได้รับเมล)
16. เลือกฟังก์ชัน **`shareWithOwners`** → กด **▶ Run** (ยิงอีเมลแชร์ปฏิทินไปเจ้าของ 2 คนอีกครั้ง)
17. เช็คอีเมล **Chutchanok.than@gmail.com** และ **pitchapawong.pw@gmail.com** (รวม Spam / Promotions) → กด **เพิ่มปฏิทิน**

## สเต็ป 5.6 — เปิดแสดงปฏิทินบนมือถือ/คอม (ทำครั้งเดียว)
18. เปิด **Google Calendar** → กด **☰** → ติ๊กเปิด **Catcha Hotel** (สีชมพู — เหมือนในภาพ)

## สเต็ป 6 — เผยแพร่เป็นเว็บแอป
19. มุมขวาบน → **Deploy** → **New deployment**
20. ไอคอนเฟือง ⚙️ → เลือก **Web app**
21. ตั้งค่า:
    - **Execute as:** Me (Stopstop.w)
    - **Who has access:** Anyone
22. กด **Deploy** → ก็อป **Web app URL** ที่ได้มา (ลิงก์ยาวๆ)

## สเต็ป 7 — ทดสอบ 🎉
23. เปิด Web app URL → กรอกจองสักคิว → กด **บันทึกการจอง**
24. เปิด Google Calendar → ดูในปฏิทิน **Catcha Hotel** (สีชมพู) → ต้องเห็นนัด 🛁 หรือ 🏠

---

## ถ้าติดปัญหา
- **ปุ่มบันทึกไม่ขึ้นเด้ง Calendar** → เปิดผ่าน "Web app URL" ใช่ไหม? (เปิดไฟล์ตรงๆ จะเป็นแค่ตัวอย่าง ไม่ต่อหลังบ้าน)
- **ไม่ได้รับอีเมลแชร์ปฏิทิน** → รัน `shareWithOwners` ใน Apps Script แล้วเช็ค Spam/Promotions
- **นัดไม่โผล่บนมือถือ** → ตรวจว่าเปิดแสดงปฏิทิน **Catcha Hotel** แล้ว (สเต็ป 5.6) + Deploy เวอร์ชันใหม่
- **แก้อีเมลเจ้าของ** → แก้ที่ `CONFIG.OWNER_EMAILS` บนสุดของ `Code.gs` แล้วรัน `setup` ใหม่
- แก้โค้ดแล้วต้อง **Deploy → Manage deployments → ✏️ → Version: New version** ทุกครั้ง เว็บถึงจะอัปเดต
