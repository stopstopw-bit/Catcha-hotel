# คู่มือติดตั้งร้านใหม่ (Demo / ลูกค้าจริง)

ทำตามนี้ได้เครื่องเปล่า 1 เครื่องต่อ 1 ร้าน ใช้เวลาประมาณ **15–20 นาที**
ทุกขั้นตอน copy-paste ได้ ไม่ต้องแก้โค้ด

> **สำคัญ:** 1 ร้าน = 1 Supabase project + 1 Vercel project เสมอ
> ห้ามให้ 2 ร้านใช้ฐานข้อมูลเดียวกัน เพราะข้อมูลลูกค้าจะปนกัน

---

## ภาพรวม 5 ขั้น

| ขั้น | ทำอะไร | เวลา |
|---|---|---|
| 1 | สร้างฐานข้อมูล (Supabase) | 5 นาที |
| 2 | ขึ้นเว็บ (Vercel) | 5 นาที |
| 3 | สร้างตาราง | 2 นาที |
| 4 | ต่อ LINE | 5 นาที |
| 5 | ตั้งค่าร้าน + ส่งมอบ | 3 นาที |

## ขั้นที่ 1 — สร้างฐานข้อมูล (Supabase)

1. ไป [supabase.com](https://supabase.com) → **New project**
   - ตั้งชื่อตามร้าน เช่น `meowmeow-hotel`
   - Region เลือก **Southeast Asia (Singapore)** — ใกล้ไทยที่สุด
   - ตั้ง Database Password แล้ว **จดไว้** (ใช้ในขั้นที่ 2)
2. รอสร้างเสร็จ ~2 นาที
3. เก็บค่า 3 ตัวนี้ไว้ (จะใช้ในขั้นที่ 2):

| ไปที่ | copy อะไร |
|---|---|
| Settings → API | **Project URL** |
| Settings → API | **service_role** key (อันยาว ๆ อันล่าง — ไม่ใช่ anon) |
| Settings → Database → Connection string → **URI** | ทั้งบรรทัด (แทน `[YOUR-PASSWORD]` ด้วยรหัสที่จดไว้) |

> ⚠️ `service_role` key คือกุญแจเปิดฐานข้อมูลทั้งหมด **ห้ามส่งให้ลูกค้า ห้ามใส่ในที่สาธารณะ**

---

## ขั้นที่ 2 — ขึ้นเว็บ (Vercel)

1. ไป [vercel.com](https://vercel.com) → **Add New → Project** → เลือก repo นี้
2. **Root Directory** ตั้งเป็น `webapp`
3. ใส่ Environment Variables ให้ครบตามตารางนี้ (Settings → Environment Variables)

### จำเป็น — ไม่มีไม่ทำงาน

| ตัวแปร | ใส่อะไร |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | Project URL จากขั้นที่ 1 |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role key จากขั้นที่ 1 |
| `DATABASE_URL` | Connection string (URI) จากขั้นที่ 1 |
| `NEXT_PUBLIC_APP_URL` | URL ของเว็บนี้ เช่น `https://meowmeow.vercel.app` |
| `ADMIN_CODE` | **รหัสเข้าหลังบ้านของร้านนี้** — ตั้งใหม่ทุกร้าน ห้ามซ้ำ |
| `SESSION_SECRET` | ข้อความสุ่มยาว ๆ (ดูวิธีสร้างด้านล่าง) |

**สร้าง `SESSION_SECRET`** — เปิด Terminal พิมพ์:
```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

### ไม่จำเป็น — ใส่ทีหลังได้

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `TELEGRAM_BOT_TOKEN` + `TELEGRAM_OWNER_CHAT_IDS` | แจ้งเตือนเข้า Telegram ของร้าน |
| `CRON_SECRET` | ป้องกัน cron (เตือนก่อนเข้าพัก / backup) |
| `GOOGLE_*` | ต่อ Google Calendar / Sheets |

> **ห้ามใส่** `SEED_DEMO_DATA` — ถ้าไม่ใส่ ระบบจะเริ่มจากศูนย์ ซึ่งเป็นสิ่งที่เราต้องการ

4. กด **Deploy** รอ ~2 นาที

## ขั้นที่ 3 — สร้างตาราง

เข้า `https://<เว็บของร้าน>/admin` → ใส่ `ADMIN_CODE` ที่ตั้งไว้ → เมนู **ติดตั้ง**

กด **⚡ สร้างตารางอัตโนมัติ** — ถ้า `DATABASE_URL` ถูกต้องจะเสร็จในไม่กี่วินาที

> ถ้าปุ่มกดไม่ได้ ให้ใช้วิธีสำรอง: กด **📋 Copy SQL** แล้วเอาไปวางใน
> Supabase → SQL Editor → Run

### เปิดระบบอัปเดตฐานข้อมูลอัตโนมัติ (ทำครั้งเดียว)

ไป Supabase → **SQL Editor** → วางแล้วกด Run:

```sql
create or replace function public.exec_sql(sql text)
returns void
language plpgsql
security definer
set search_path = public
as $$
begin
  execute sql;
end;
$$;

revoke all on function public.exec_sql(text) from public;
grant execute on function public.exec_sql(text) to service_role;

notify pgrst, 'reload schema';
```

หลังจากนี้เวลามีฟีเจอร์ใหม่ที่ต้องเพิ่มคอลัมน์ ระบบจะอัปเดตเองตอนเปิดหลังบ้าน
**ไม่ต้องแตะ SQL อีกเลย**

✅ **เช็ค:** กลับไปหน้าติดตั้ง กด 🔄 ตรวจสอบอีกครั้ง — ต้องเขียวครบทุกบรรทัด

## ขั้นที่ 4 — ต่อ LINE

### 4.1 สร้าง Messaging API channel
1. ไป [developers.line.biz](https://developers.line.biz) → Create channel → **Messaging API**
2. **Messaging API** tab → **Issue** Channel Access Token (long-lived) → copy
3. ปิด **Auto-reply messages** และ **Greeting messages** (ไม่งั้นบอทจะตอบทับ)

### 4.2 สร้าง LIFF (แอปลูกค้า)
1. **LIFF** tab → Add
   - Size: **Full**
   - Endpoint URL: `https://<เว็บของร้าน>/app`
   - Scopes: ติ๊ก `profile` และ `openid`
2. copy **LIFF ID**

### 4.3 ใส่ในระบบ
หลังบ้าน → **ติดตั้ง → LINE** → วาง Channel Access Token + LIFF ID → บันทึก

> ใส่ผ่านหน้าเว็บได้เลย ไม่ต้องแก้ Vercel

### 4.4 ตั้ง Webhook
กลับไป LINE Developers → Messaging API → **Webhook URL**:
```
https://<เว็บของร้าน>/api/line/webhook
```
เปิด **Use webhook** → กด **Verify** ต้องขึ้น Success

## ขั้นที่ 5 — ตั้งค่าร้าน

หลังบ้าน → **ตั้งค่า** กรอกให้ครบ (สำคัญมาก เพราะขึ้นบนการ์ดที่ส่งหาลูกค้า):

- [ ] **ชื่อร้าน** — ขึ้นบนใบเสร็จและการ์ดขอรีวิว
- [ ] **ที่อยู่ + ลิงก์ Google Maps** — ขึ้นบนการ์ดยืนยันนัด
- [ ] **เบอร์โทร / LINE OA**
- [ ] **บัญชีธนาคาร** — ชื่อบัญชี เลขบัญชี ธนาคาร
- [ ] **ลิงก์รีวิว** (Google Maps review)
- [ ] **ห้องพัก + ราคา** / **บริการอาบน้ำ + ราคา**

> ถ้าไม่กรอก ระบบจะ **ซ่อน** บรรทัดนั้นบนการ์ด (ไม่ใส่ค่ามั่ว) — แต่การ์ดจะดูไม่ครบ

## ✅ เช็คก่อนส่งมอบ

ทดสอบตามนี้ให้ผ่านหมดก่อนส่งให้ลูกค้า:

- [ ] เปิด `/admin` แบบไม่ล็อกอิน → ต้องเด้งไปหน้าใส่รหัส
- [ ] เปิด `https://<เว็บ>/api/customers` ในโหมดไม่ระบุตัวตน → ต้องขึ้น `unauthorized`
- [ ] ล็อกอินได้ด้วย `ADMIN_CODE` ที่ตั้งไว้
- [ ] หน้าลูกค้า / ตารางนัด / คิดเงิน → **ว่างเปล่าทั้งหมด ไม่มีข้อมูลปลอม**
- [ ] เพิ่มลูกค้า 1 คน + ออกบิล 1 ใบ → กดรับเงิน → ขึ้นในรายรับ
- [ ] เปิด LIFF จาก LINE → หน้าสมัครสมาชิกขึ้นปกติ
- [ ] ส่งการ์ดยืนยันนัดให้ตัวเอง → ชื่อร้าน/แผนที่ **ต้องเป็นของร้านนี้ ไม่ใช่ CatCha**

---

## ส่งมอบให้ลูกค้า

ส่ง 3 อย่างนี้:
1. ลิงก์หลังบ้าน `https://<เว็บของร้าน>/admin`
2. รหัสเข้าใช้ (`ADMIN_CODE`)
3. QR code ให้ลูกค้าของร้านแอดไลน์ (อยู่ในหน้า ลูกค้า → 🛠️ เครื่องมือ)

**ห้ามส่ง:** service_role key, `DATABASE_URL`, `SESSION_SECRET`

> แนะนำ: สร้างบัญชีพนักงานให้ลูกค้าใช้แทนรหัสเจ้าของ
> (ตั้งค่า → ขั้นสูง → พนักงาน) จะได้จำกัดเมนูที่เห็นได้

## แก้ปัญหาที่เจอบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| หน้าติดตั้งขึ้นแดง "ตารางไม่ครบ" | ยังไม่ได้รัน schema — กลับไปขั้นที่ 3 |
| ส่งการ์ดแล้วขึ้น "ยังไม่ได้ตั้ง LINE" | ยังไม่ได้ใส่ Channel Access Token (ขั้น 4.3) |
| ลูกค้าเปิด LIFF แล้วจอขาว | Endpoint URL ใน LIFF ไม่ตรงกับ `NEXT_PUBLIC_APP_URL` |
| ล็อกอินแล้วเด้งออกตลอด | ยังไม่ได้ตั้ง `SESSION_SECRET` หรือเพิ่งเปลี่ยนค่า (ให้ล็อกอินใหม่) |
| การ์ดขึ้นชื่อร้านผิด | ยังไม่ได้กรอกชื่อร้านใน ตั้งค่า (ขั้นที่ 5) |
| กดรับเงินแล้วขึ้น "ส่งใบเสร็จไม่ได้" | ปกติ ถ้ายังไม่ต่อ LINE — **เงินลงบัญชีเรียบร้อยแล้ว** |

## ให้ลูกค้าลองทีละคน — ใช้ demo ตัวเดียวซ้ำได้

ถ้าให้ลูกค้าทดลองทีละคน **ไม่ต้องสร้างโปรเจกต์ใหม่ทุกคน** ใช้เครื่อง demo
ตัวเดิมแล้วล้างข้อมูลก่อนส่งต่อ — ประหยัดโควตา Supabase (ฟรี 2 โปรเจกต์)
และไม่ต้องตั้งค่า LINE ใหม่ทุกรอบ

**ขั้นตอนส่งต่อให้คนถัดไป:**

1. Supabase → SQL Editor → วาง `supabase/reset-demo.sql` → Run
   - เช็คให้ชัวร์ว่าเปิดโปรเจกต์ **demo** อยู่ ไม่ใช่ของร้านจริง
2. ดูผลท้ายสคริปต์ — ต้องเป็น **0 ทุกบรรทัด**
3. เปลี่ยน `ADMIN_CODE` ใน Vercel เป็นรหัสใหม่ → Redeploy
   (คนเก่าจะเข้าไม่ได้อีก)
4. ส่งลิงก์ + รหัสใหม่ให้คนถัดไป

> Token ของ LINE/Telegram **ไม่ถูกล้าง** — ต่อไว้ครั้งเดียวใช้ได้ตลอด
> ส่วนชื่อร้าน/บัญชีธนาคาร/ห้องพัก จะถูกล้าง ลูกค้าคนถัดไปได้กรอกเองตั้งแต่ต้น

## หมายเหตุสำหรับทดลองใช้ฟรี 15 วัน

ตอนนี้ยังไม่มีระบบนับวันอัตโนมัติ ทำแบบ manual ไปก่อน:
- จดวันที่เริ่มไว้ในไฟล์/Google Sheet
- ครบกำหนดแล้วไม่ต่อ → ปิดที่ Vercel (Settings → General → Pause Project)
- ข้อมูลยังอยู่ครบ ถ้าลูกค้ากลับมาจ่ายก็เปิดต่อได้ทันที

ถ้าเริ่มมีลูกค้าเกิน ~10 ร้าน ค่อยลงทุนทำระบบสมัคร/เก็บเงินอัตโนมัติ
