# โปสเตอร์ห้อง / บริการรับส่ง

วางไฟล์รูปใหม่ในโฟลเดอร์นี้ แล้วรัน:

```bash
bash webapp/scripts/sync-posters.sh
```

| ชื่อไฟล์ | ใช้กับ |
|----------|--------|
| `cozy-duo.jpg` | ห้อง Cozy Duo |
| `mini-duo.jpg` | ห้อง Mini Duo |
| `cat-tower.jpg` | ห้อง Cat Tower Suite |
| `catflix.jpg` | ห้อง Catflix & Chill |
| `mid-cozy.jpg` | ห้อง Mid Cozy |
| `mini-meow.jpg` | ห้อง MiNi Meow |
| `transport.jpg` | บริการรับส่งน้องแมว |

ไฟล์จะถูกคัดลอกไปที่ `webapp/public/catalog/`
